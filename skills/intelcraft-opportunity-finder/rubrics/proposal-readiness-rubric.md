# Proposal Readiness Rubric

Measures whether the applicant can submit a strong application quickly. Score 0–2 per row; sum to 0–10.

| Component | 0 (missing) | 1 (draft/partial) | 2 (ready) |
|---|---|---|---|
| Core narrative (problem, solution, outcomes) |  |  |  |
| Budget + justification |  |  |  |
| Evidence base (data, prior results, testimonials) |  |  |  |
| Organizational documents (financials, governance, tax letter / fiscal sponsor agreement) |  |  |  |
| Relationships (letters of support, references, partners) |  |  |  |

## Interpretation
- **8–10: Submission-ready.** Quick-apply opportunities are realistic this week.
- **5–7: Assembly required.** Target Level 2–3 opportunities; fill gaps in parallel.
- **2–4: Foundation-building.** Target rolling/lightweight opportunities only; prioritize creating the missing components.
- **0–1: Not ready.** Do readiness work before searching widely — otherwise the search wastes effort.

## Use
- Record the score in the intake and every scorecard.
- Match opportunities to readiness: never shortlist a Level 4–5 opportunity for a readiness ≤4 applicant without flagging the gap and a build plan.
