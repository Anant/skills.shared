# Open Source and Public-Interest Technology Sources

> **Verification reminder:** OSS funding programs frequently change scope and open/close cycles. Verify each program's current call and whether it funds new work vs. maintenance of existing widely-used software.

## Open Source Funding
- **Sovereign Tech Fund (Agency)** — public funding for critical open digital infrastructure; strong for maintenance/security of widely-used components. Level 3. [verify — sovereign.tech]
- **NLnet Foundation** — grants for open internet technologies (privacy, trust, open standards); small-to-mid grants; famously lightweight application. Level 2. [verify — nlnet.nl]
- **Open Collective / Open Source Collective** — fiscal hosting + community funding rails; enables sponsorships and some grant programs. Level 1–2. [verify — opencollective.com]
- **GitHub Sponsors** — recurring individual/org sponsorship for maintainers. Level 1. [verify — github.com/sponsors]
- **Mozilla-related programs** — internet health, trustworthy AI, and open-source support programs; check current calls. Level 2–3. [verify — foundation.mozilla.org]
- **Linux Foundation-related programs** — project hosting, targeted funds, security programs. [verify — linuxfoundation.org]
- **Research software funding** — programs supporting software underpinning research (research software sustainability initiatives, science philanthropy OSS programs). Level 3. [verify per program]
- **Open-source ecosystem grants** — language/ecosystem foundations (Python, Rust, etc.) and their grant/workgroup funding. Level 2. [verify per foundation]

## Positioning Notes
- OSS funders respond to: adoption metrics, dependency criticality, maintenance burden, security posture, governance health.
- Public-interest tech funders respond to: community accountability, equity outcomes, sustainability plan, and public-good licensing. Open licensing of curriculum is a differentiator — say so explicitly.
