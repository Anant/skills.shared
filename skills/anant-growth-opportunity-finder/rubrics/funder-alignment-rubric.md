# Funder Alignment Rubric

Assesses how closely a specific funder's demonstrated behavior (not just website language) matches the applicant. Score 0–2 each; sum to 0–10.

| Signal | 0 | 1 | 2 |
|---|---|---|---|
| **Stated priorities** | No overlap | Adjacent | Direct overlap with project language |
| **Actual grant history** | Never funds this kind of work | Occasionally | Repeatedly funds similar projects/orgs |
| **Grantee resemblance** | Grantees look nothing like applicant (size, type, geography) | Partial resemblance | Applicant fits the grantee pattern |
| **Values compatibility** | Conflicts with applicant ethics/exclusions | Neutral | Reinforcing (e.g., open licensing, equity commitments) |
| **Accessibility of pathway** | Invitation-only, no contact route | Relationship possible | Open application or clear LOI door |

## Interpretation
- **8–10:** Aligned funder — mirror language confidently; consider multi-year ask.
- **5–7:** Workable — tailor framing; verify with a program-officer conversation if possible.
- **2–4:** Misaligned in behavior even if language matches — deprioritize; beware buzzword traps.
- **0–1:** Do not pursue.

## Buzzword-Trap Check
If stated priorities score 2 but grant history scores 0, the funder *talks* about the theme but doesn't fund it. Flag explicitly: "language fit without funding evidence."
