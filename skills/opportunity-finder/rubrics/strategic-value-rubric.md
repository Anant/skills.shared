# Strategic Value Rubric

Score 0–2 on each dimension; sum to 0–10 (feeds the composite's strategic-value criterion).

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| **Relationship value** | Transactional funder | Funder engages grantees | Funder known for long-term partnership and intros to peers |
| **Credibility signal** | Unknown funder | Recognized in-sector | Prestige award that unlocks other funders |
| **Recurring potential** | One-time only | Renewal possible | Explicit multi-year or reliable annual cycle |
| **Ecosystem access** | None | Cohort or event access | Active network, convenings, co-funding pathways |
| **Mission advancement** | Money only | Funds core work | Funds the exact strategic priority + amplifies it publicly |

## Interpretation
- **8–10:** Pursue even at higher effort or lower probability; consider relationship-building before applying.
- **5–7:** Solid strategic upside; normal prioritization.
- **2–4:** Treat as purely financial; weight speed and probability instead.
- **0–1:** Only worth it if fast and probable.

## Note
High strategic value can justify pursuing an opportunity scoring 60–74 on the composite; say so explicitly in the recommendation.
