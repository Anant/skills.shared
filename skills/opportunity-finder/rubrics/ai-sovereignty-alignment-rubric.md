# AI Sovereignty / Alignment / Safety / Governance Fit Rubric

Evaluates whether a funder is likely to support AI sovereignty, AI alignment, AI safety, or AI governance work. Score each 0–5 (0 = no evidence; 3 = adjacent/implied; 5 = explicit, funded, recent). Total: 0–50.

| # | Signal | Score (0–5) |
|---|---|---:|
| 1 | Explicit AI governance language |  |
| 2 | Explicit AI safety or alignment language |  |
| 3 | Supports public-interest technology |  |
| 4 | Supports democratic technology governance |  |
| 5 | Supports local or community control of technology |  |
| 6 | Supports digital sovereignty or digital public infrastructure |  |
| 7 | Supports responsible innovation |  |
| 8 | Supports open-source infrastructure |  |
| 9 | Supports research, evaluation, or policy |  |
| 10 | Supports education or capacity-building around AI |  |

## Interpretation
- **40–50: Direct fit** — use the funder's own safety/governance vocabulary; lead with the AI-specific thesis.
- **30–39: Strong adjacent fit** — bridge from their core theme (democracy, public interest, education) to the AI work.
- **20–29: Possible narrative fit** — the AI angle is secondary; lead with the funder's theme, AI as method.
- **10–19: Weak fit** — pursue only if other rubric scores are exceptional.
- **0–9: Not relevant** — reject for AI-framed asks.

## Evidence Standards
Score from: program pages, published strategies, recent grants lists, staff writing, and RFP language. A funder gets 5 on a row only with *funded examples*, not aspirational statements.
