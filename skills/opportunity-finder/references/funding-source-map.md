# Funding Source Map (Master Routing)

Use this map to decide which reference files to consult based on the funding thesis. Then verify every candidate opportunity from its primary source before reporting it.

> **Verification reminder:** Nothing in these reference files should be treated as currently open. Deadlines, programs, and eligibility change frequently. Always confirm status from the funder's own page and record it in the source verification log.

| If the thesis involves… | Consult |
|---|---|
| Any project (baseline sweep) | grant-databases.md |
| Federal/state/local funding, workforce, digital equity | government-sources.md |
| Philanthropic support, general nonprofit funding | foundation-sources.md |
| Individual support, research/policy/founder fellowships | fellowship-sources.md |
| AI safety, alignment, governance, sovereignty, policy | ai-alignment-ai-governance-sources.md |
| Curriculum, education, adult learning, upskilling | education-workforce-sources.md |
| Open source, civic tech, digital public infrastructure | open-source-public-interest-tech-sources.md |
| Academic partnerships, research center funding | university-and-research-center-sources.md |
| Cloud credits, ecosystem funds, corporate CSR | corporate-philanthropy-sources.md |
| Non-US applicants or global beneficiaries | international-sources.md |

## Search sequence (recommended)

1. **Aggregators first** (grant-databases.md) for breadth — 15–30 minutes.
2. **Category deep-dive** on the 2–3 best-fit categories above.
3. **Named-funder pass**: for each promising funder, go directly to their grants/apply page.
4. **Recency pass**: search news and announcements for new programs in the theme (last 12 months).
5. **Verification pass**: primary-source check on everything that survived.

## Coverage tiers

- **Tier 1 (always check):** aggregator databases + the single best-fit category file.
- **Tier 2 (landscape reports):** all category files relevant to the thesis.
- **Tier 3 (strategic engagements):** add university centers, international, and corporate ecosystem sources.
